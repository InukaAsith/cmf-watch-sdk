# LVGL apps (ABI 1.2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** apps build their screens from the watch's stock LVGL widgets and fonts through a validated command buffer.

**Architecture:** the app thread encodes records into a buffer (SDK `cmf_wp2_app::lv`) and calls `api.lv_submit`;
the loader's UI tick on `ui_service` validates the whole batch with `wp2_core::lvcmd` against a copy of its handle
table, then executes it with stock LVGL entries (`fw/wp2-loader/src/lv.rs`). Events return through the existing
queue as kind `LV = 8`. The loader owns the root object, the fonts and the handle table and tears them down on exit.

**Tech Stack:** Rust `no_std` (`thumbv7em-none-eabi`), stock LVGL 8.3 in `app.bin` JX402 `1.0.0.73`, Python e2e
harness (`tests/e2e/harness.py`), QEMU emulator via `cmf-watch-utils`.

**Spec:** `docs/specs/2026-11-11-lvgl-apps-design.md` (format table, budgets, return codes). Background:
`docs/recon-lvgl.md` (entries, heap, thread), `docs/abi-1.1.md` (how 1.1 extended the table).

## Global Constraints

- AGENTS.md hard rules: no writes to a physical watch without the owner's yes; no firmware, vendor resources,
  built apps or personal data in commits; no code from `cmf-watch-utils`; addresses for `1.0.0.73` only.
- Every LVGL call runs on `ui_service` (view proc, LVGL event callback, `lv_timer`); never on the app thread.
- `MAX_OBJS = 192`, `MAX_FONTS = 4`, `TEXT_MAX = 128`, `OPTIONS_MAX = 240`, `BATCH_MAX = 2048`.
- Event kind `LV = 8`; `ABI_MINOR = 2`; `LOADER_ABI_MINOR = 2`.
- An app stack is 8 KiB with no guard: no buffer over ~1 KiB on the stack (the SDK's batch buffer is a `static`).
- Verification suites (AGENTS.md) pass after every task: Python unittest, `sdk` and `fw/wp2-core` cargo tests.
- Emulator runs: a unique `WP2_NETSIM_INSTANCE` per parallel run, in a pane, never in the background.

## Review Focus

- An app built with the 1.2 SDK under the simulator or a 1.1 loader: the table has no `lv_submit`; the SDK must
  read `abi_minor` first and return `-95`, never call past the table (Task 3 test `submit_refuses_old_table`).
- Deleting a parent, or a scroll target that a `SCROLLBAR` listens to: every descendant and the bar must be freed
  in the handle table, and a later record using them rejected (Task 2 test `del_frees_descendants_and_bars`).
- A slider dragged fast floods the 16-event queue: VALUE_CHANGED for one handle must coalesce, not push BUTTON
  out (Task 4 test `value_events_coalesce`).
- BUTTON while the app waits inside `lv_submit`, and force stop 1000 ms later: no LVGL call after the root is
  deleted, no leak (Task 5 e2e `test_stop_inside_submit`).
- A batch that fails validation halfway: nothing on screen changes and the handle table is unchanged (Task 2
  test `invalid_batch_changes_nothing`, Task 5 e2e checks the frame).

### Task 2: `wp2_core::lvcmd`: decode, validate, handle table

**Files:**
- Create: `fw/wp2-core/src/lvcmd.rs`, `tests/fixtures/lvcmd-golden.bin` (written by Task 3's SDK test; until then
  the Task 2 golden test builds the same bytes inline)
- Modify: `fw/wp2-core/src/lib.rs` (`pub mod lvcmd;`)

**Interfaces:**
- Produces:
  - `pub enum Class { Obj, Label, Btn, Arc, Bar, Slider, Roller, ScrollBar }` (`u8` values 0..=6, `ScrollBar` = 7
    is loader-internal, never accepted in CREATE).
  - `pub enum Rec<'a> { Create { h: u16, class: Class, parent: u16 }, Del(u16), Size { h, w: i32, hh: i32 },
    Align { h, align: u8, x: i16, y: i16 }, Flags { h, set: u32, clear: u32 }, Style { h, prop: u16, sel: u32,
    value: i32 }, Font { slot: u8, font: u8 }, Text { h, s: &'a [u8] }, Value { h, v: i32, anim: bool },
    Range { h, min: i32, max: i32 }, Options { h, mode: u8, s: &'a [u8] }, Events { h, mask: u8 },
    Flex { h, flow: u8, main: u8, cross: u8, track: u8 }, ScrollBar { h, target: u16 }, Knob(u16),
    Angles { h, start: u16, end: u16, rot: u16 } }` with the op numbers and payloads of the spec table.
  - `pub struct Table { class: [u8; MAX_OBJS + 1], parent: [u16; MAX_OBJS + 1] }` (`0xFF` = free; index 0 = root,
    class Obj), `Table::new()`, `Table::reset()`, `fn class(&self, h) -> Option<Class>`.
  - `pub fn records(buf: &[u8]) -> impl Iterator<Item = Result<Rec<'_>, Error>>`.
  - `pub fn validate(buf: &[u8], t: &Table, fonts_open: u8) -> Result<(), Error>`: dry run on a copy of `t`.
  - `pub fn apply(t: &mut Table, r: &Rec) ` updates the table for Create/Del/ScrollBar (the loader calls it per
    record after the LVGL call); `pub fn freed_by_del(t: &Table, h: u16) -> impl Iterator<Item = u16>`
    (descendants in post-order, scroll bars whose target is among them included).
  - `pub enum Error { Malformed, BadHandle, BadClass, BadValue, Budget }` with `pub fn code(self) -> i32`
    (`Budget` → `-12`, others `-22`).
- [ ] **Step 1: Write the failing tests** in `lvcmd.rs`:
  - `golden_batch_decodes`: the spec's example batch (CREATE 1 label on root, FONT slot 0 font 7, STYLE 1
    `TEXT_FONT` 0, TEXT 1 "Привет", ALIGN 1 center 0 0, EVENTS 1 CLICKED) decodes to exactly those `Rec`s.
  - `truncated_and_unknown_records_are_malformed`: `len` past the end, unknown op, payload length not matching
    the op → `Err(Malformed)`.
  - `handles_are_checked`: CREATE on a used handle, on 0 or `> 192`, with a free parent; any op on a free handle
    → `BadHandle`; VALUE on a label, OPTIONS on a bar, TEXT on an arc → `BadClass`.
  - `values_are_checked`: STYLE prop not in `STYLE_PROPS`; FLAGS bit outside the whitelist; ALIGN 22; FONT slot 4
    or font 16; TEXT 129 B or invalid UTF-8; OPTIONS 241 B → `BadValue`; `TEXT_FONT` value of a slot not opened
    in this batch or before → `BadValue`.
  - `budget`: creating object 193 → `Budget`; a fifth FONT slot is impossible by range, reopening a slot is ok.
  - `del_frees_descendants_and_bars`: root → a (scrollable) → b → c, bar on a; DEL a frees a, b, c and the bar;
    a later STYLE on c → `BadHandle`.
  - `invalid_batch_changes_nothing`: a batch whose 5th record is bad leaves `Table` equal to before.

### Task 4: Loader executor

**Files:**
- Create: `fw/wp2-loader/src/lv.rs`
- Modify: `fw/wp2-loader/src/app.rs` (`API.abi_minor = 2`, `lv_submit` field, `stop_app` calls `lv::teardown()`
  before freeing the block), `fw/wp2-loader/src/main.rs` (the UI tick calls `lv::tick()` first; `input_cb` also
  serves the root), `fw/wp2-loader/src/ui.rs` (`show_app` shows the root instead of the image once it exists),
  `fw/wp2-core/src/layout.rs` (`LOADER_ABI_MINOR = 2`), `fw/wp2-core/src/events.rs` (`LV = 8`, `Queue::coalesce`)

**Interfaces:**
- Consumes: Task 1 constants, Task 2 `lvcmd::{records, validate, apply, freed_by_del, Table, Error}`.
- Produces:
  - `pub extern "C" fn submit(buf: *const u8, len: usize) -> i32` (app thread): checks `len <= BATCH_MAX` and the
    pointer lies inside the app block, publishes `(buf, len)` in a one-slot mailbox (atomics), sleeps 5 ms per
    poll until the tick stores the result.
  - `pub fn tick()` (UI thread): takes the mailbox, `validate`, executes record by record (`apply` after each
    LVGL call), stores the result.
  - `pub fn teardown()` (UI thread): deletes the root if any, closes open fonts, `Table::reset()`, clears the
    mailbox (a waiting app thread is already aborted).
  - `Queue::coalesce(&self, e: Event)`: replaces a queued event with the same `kind` and `x` instead of pushing.
- [ ] **Step 1: Write the failing host test** in `fw/wp2-core/src/events.rs`: `value_events_coalesce` → 40
  VALUE_CHANGED events for handle 3 then a BUTTON leave 2 events in the queue: the last value and the BUTTON.
- [ ] **Step 2: Run** `(cd fw && cargo test -p wp2-core --target aarch64-apple-darwin coalesce)` → fails; implement
  `coalesce`; passes.
- [ ] **Step 3: Implement `lv.rs`.** Handle → `lv_obj_t *` array beside the `Table`; root on first submit
  (`lv_obj_create(scr)`, 466×466, black `BG_COLOR`/`BG_OPA` 255, not scrollable, clickable, PRESSED/RELEASED/KNOB
  callbacks like the image), `ui::show_app` hides the image. Event trampoline: one `extern "C"` callback,
  `user_data` = handle; maps `lv_event_get_code` to `Event { kind: LV, x: handle, y: code, delta }` (`delta` =
  clamped value from the getter for VALUE_CHANGED, else 0), pushed with `coalesce` for VALUE_CHANGED. Fonts: four
  `lv_font_t` (0x20 B) statics in the loader block; `TEXT_FONT` style values become `&FONTS[slot]`. SCROLLBAR:
  `jx_scroll_bar_create(root)`, `lv_obj_set_size(bar, 462, 462)`, `set_scroll_obj`, `set_knob(1)`,
  `lv_obj_align(bar, CENTER, 0, 0)` (the stock call order, recon § Vendor components).
