# Workout iPhone companion: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An iPhone app that owns the workout program, syncs it to the `workout` watch app automatically next to
Nothing X, keeps the history forever and installs `workout`; plus the stub changes that make that possible.

**Architecture:** The stub gets a second channel key `K` derived from the pairing secret (no bind, no popup) and
sends app messages unsolicited. `workout` reports "workout in progress" in `R`. A Swift package `WireKit`
(Foundation, CryptoKit, CommonCrypto only) ports `link.py`, `channel.py`, `workout.py` and `install.py` and holds
the sync engine; the SwiftUI app adds CoreBluetooth, SwiftData and three tabs.

**Tech Stack:** Rust `no_std` (fw, sdk), Python 3.12 (`wp2apps`, unittest), Swift 6 / SwiftUI / SwiftData,
iOS 17, XcodeGen (`nix-shell -p xcodegen`).

**Spec:** `docs/specs/2026-11-13-workout-ios-design.md`

## Global Constraints

- AGENTS.md rule 1: no writes to the physical watch (OTA, install, push) without the owner's explicit yes at that
  time. Rule 2: no MAC, pairing secret, session key, real program or history in commits, logs or test output.
- The stock session key keeps working for every existing host (`wp2apps install`, `herdr`, `workout push`).
- `K = bytes.fromhex(secret)`, `secret` = the 32 hex chars `AT GETSECRET` returns (NVRAM `APP_SECRET`).
  Frame format under `K` = today's (`link.encrypt`: data ‖ crc32le, PKCS7, AES-128-CBC, IV
  `5051525354555657606162636465665A`).
- `R` = `"w1" 'R' version:u32 flags:u8` (8 B), flags bit 0 = workout in progress. Hosts accept 7 B `R` as flags 0.
- Program limits (unchanged): 7 days, 12 exercises/day, name and weight ≤ 32 B UTF-8, encoded ≤ 2048 B, rest
  default 90 s, `Ё/ё → Е/е` on encode.
- iOS app: no third-party Swift packages; iOS 17 deployment target; Russian UI; stock iOS look; free Personal Team
  signing; built `.wp2app` and `.xcodeproj` are not committed (`ios/Workout.xcodeproj` generated by XcodeGen).
- Addresses for JX402 `1.0.0.73` only.

## Review Focus

1. A stock-key host and a `K` host on the same link at once: both keep getting answers (Task 2 e2e).
2. History sync where the watch's ring wrapped (30+ new entries) or the phone already has some: no duplicates,
   no gaps in what the ring still holds (Task 6 `testMergeKeepsExistingAndSkipsDuplicates`).
3. Program edited while a workout runs on the watch: never pushed until the flag clears, then pushed once
   (Task 6 `testHoldsProgramWhileWorkoutRuns`, Task 4 e2e).
4. Name with multibyte text cut at 32 B: the phone shows the limit before encoding and the encoder cuts on a char
   boundary exactly like `clip` (Task 5 vectors include a 33 B Cyrillic name).
5. Install while `workout` runs: `BUSY` surfaces as "закройте приложение на часах", nothing half-written
   (Task 7 `testInstallBusy`).
